# Estimate Management System

## Project Overview

Estimate Management System is a web application developed using Node.js, Express.js, MySQL, and EJS. It helps manage Groups, Chains, Zones, SubZones, Brands, Estimates, and Invoices.

## Technologies Used

- Node.js
- Express.js
- MySQL
- EJS
- Bootstrap
- HTML
- CSS
- JavaScript

## Features

- User Login
- Dashboard
- Group Management
- Chain Management
- Zone Management
- SubZone Management
- Brand Management
- Estimate Management
- Invoice Management

## Installation

2. Install dependencies

```

```
